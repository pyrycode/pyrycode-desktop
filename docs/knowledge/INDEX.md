## Features

- [Conversation shell](features/conversation-shell.md) — the renderer's first screen: a scrollable message thread above a bottom-pinned composer, mirrored from the mobile Conversation Thread design (static, inert; #1).
- [Session store](features/session-store.md) — the renderer's single source of truth for the active session's connection status + conversation messages, mutated through a sealed action union; the state seam #3 dispatches into and #12 reads (#2).
- [Daemon-event channel](features/daemon-event-channel.md) — the typed background→window event pipe: a sealed `DaemonEvent` union in `src/shared/ipc/`, the single `emitDaemonEvent` send path, and a receive-only `onDaemonEvent` subscription on `window.pyry` (#18).
- [Command channel](features/command-channel.md) — the mirror-image window→background command pipe: a sealed `RendererCommand` union + pure `sendMessageCommand` + `isRendererCommand` boundary guard in `src/shared/ipc/`, a typed `sendCommand` on `window.pyry`, and an `onCommand` receiver seam that validates each command at the untrusted renderer→main boundary (#17).
- [Daemon-event bridge (renderer)](features/daemon-event-bridge.md) — the renderer translation half: pure `translateDaemonEvent` maps each `DaemonEvent` to a `SessionAction`, and the `useDaemonEventBridge` hook pipes `onDaemonEvent → translate → dispatch` into the app-singleton store, unsubscribing cleanly on teardown (#19).
- [Relay connection](features/relay-connection.md) — the background-process connection primitive: `createRelayConnection` opens one `wss://` socket with caller-supplied headers, a 30s/30s heartbeat, a 1 MiB frame cap, carrying raw frames both ways as opaque bytes and funnelling every failure into one terminal `closed` event; semantics-blind, log-free, no reconnect (that's #22). Adds `ws`, the project's first network dependency (#21).
- [Relay supervisor](features/relay-supervisor.md) — the resilience layer over #21: `createRelaySupervisor` wraps `createRelayConnection` by injection so the layers above see a connection that heals itself — re-dials after a retryable close with capped exponential backoff + ±20% jitter (1s→30s), resets the backoff after ≥60s continuously up, treats a fatal close code (`{4401,4421,4426}`, injected) as terminal to block a reconnect-storm DoS, tears down with no dangling timers, and forwards inbound frames byte-for-byte. Main-process only, log-free, no new dependency (#22).
- [Secure store](features/secure-store.md) — the background-process secret-at-rest primitive: a key-domain-blind `createSecureStore` (`set`/`get`/`delete` over named `Uint8Array` blobs) that encrypts at rest with Electron `safeStorage` (OS keychain), fails closed when the keychain is unavailable (incl. the Linux `basic_text` obfuscation backend) so plaintext never hits disk, and ships its keychain + filesystem edges as injected seams (real adapters: `electronSecretEncryption` base64-bridged over `safeStorage`, `fileSecretPersistence` traversal-safe + atomic). Main-process only, log-free, no new dependency; the foundation #43/#44 consume (#42).
- [Device static keypair](features/device-keypair.md) — the desktop client's stable Noise_IK identity: a device static X25519 keypair generated once and persisted through #42's secure store, so every launch reads the same pair without the private key ever leaving the store or reaching the renderer. `createDeviceKeypairStore` is a pure core over two injected seams (`SecureStore` type-only + a `KeyPairGenerator`, real impl `noiseKeyPairGenerator` over `noise-c.wasm` `CreateKeyPair(NOISE_DH_CURVE25519)`); `ensure()` is generate-once (memoized promise + persisted 64-byte `priv‖pub` blob as source of truth), fail-loud on corruption (never silently regenerates), and log-free. Main-process only, no new dependency; the first consumer of #42, feeding the eventual Noise_IK handshake (#43).
- [Paired-server store](features/paired-server-store.md) — the persisted pairing record: the `{server, relay, token, server_static_pubkey}` QR/paste tuple serialized to one opaque JSON blob and stored through #42's secure store, so the client reconnects and drives the Noise_IK handshake each launch without re-pairing. `createPairedServerStore` is a pure core over one injected `SecureStore` seam (serialization is pure — no second adapter); `save` overwrites (re-pair), fail-closed on keychain-unavailable; `load` returns `null` only on genuine absence — a decrypt failure propagates and a present-but-malformed blob throws `MalformedPairedServerRecordError`, so a tampered record is never silently mistaken for never-paired. `PairedServerRecord` aliases `QrPayload` (wire drift is a type error). Main-process only, log-free, no new dependency; the second consumer of #42 (#44).
- [Wire codec](features/wire-codec.md) — the transport's serialization layer in `src/main/transport/codec.ts`: pure `encode/decodeInnerFrame` + `encode/decodeEnvelope` + strict `base64Std*` + the one default-injecting `makeHelloClientPayload`, producing bytes byte-identical to pyrycode-mobile. Encode is total; the `decode*` functions fail closed with a category-only `WireDecodeError`; `Envelope.payload` stays opaque (`unknown`). Main-process only (structural renderer isolation); tightens `types.ts` optionals to `number | undefined` (never `null`) (#5).
