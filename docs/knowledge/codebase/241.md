# #241 — Wire `create_conversation` through the transport → `conversationCreated` daemon event

Transport half of the "create a new conversation" vertical (split from #142). The renderer FAB that
fires the command and opens the new thread is the sibling render ticket #242, blocked by this one.
Shipped as PR #244 (`caadb38`), architect self-review **PASS**. Security-sensitive (a new outbound
frame + a new inbound decode on the internet-exposed relay/Noise surface, plus a new untrusted
renderer→main command member); size S; the write-side twin of #139 (`list_conversations` →
`conversations`).

## Summary

The daemon speaks a request/reply pair: the client sends `create_conversation{is_promoted, name,
cwd}` (all three server-defaultable, `null` = "let the daemon choose") and the daemon replies
`conversation_created` carrying the new conversation's summary. Ten production files, one new
(`createConversationEnvelope.ts`):

- **Wire types** (`src/shared/wire/types.ts`) — `'create_conversation'`/`'conversation_created'` join
  `EnvelopeType`; `CreateConversationPayload` (`is_promoted`/`name`/`cwd`, each `T | null` — present
  and nullable, **not** optional, since the daemon's Go struct uses `*T` without `omitempty`) and
  `ConversationCreatedPayload` (`id`, `is_promoted`, `cwd`, `name: string | null`, `last_used_at`) —
  its **own** 5-field shape, deliberately **not** a reuse of the existing 7-field `ConversationSummary`
  (the daemon excludes `is_archived`/`last_message_ts` on a create reply, spec #274).
- **Command** (`src/shared/ipc/commands.ts`) — a seventh `RendererCommand` member, `createConversation
  { payload: CreateConversationPayload }`, guarded by `isCreateConversationPayload` — a structural-
  minimum check on **type**, so `null` is accepted (the daemon-default signal) while a missing/
  `undefined` key is rejected. No constructor: like `requestSnapshot`, the render side (#242) builds
  the literal inline.
- **Builder** (new `src/main/transport/createConversationEnvelope.ts`) — `buildCreateConversation`,
  a payload-carrying builder cloned from `sendMessageEnvelope.ts`/`requestSnapshotEnvelope.ts`.
  `JSON.stringify` preserves the explicit `null`s verbatim, so an all-null payload serializes to
  `{"is_promoted":null,"name":null,"cwd":null}` — exactly the daemon's own encoding. Main-process
  only, never re-exported to a renderer barrel.
- **Connection method** (`daemonConnection.ts`) — `createConversation(payload)`, the `send` twin
  (inert no-op when `driver === null`, shares the one `nextEnvelopeId` counter, never throws — parity
  #490). Builds a **fresh literal** naming exactly the three modeled fields before calling the
  builder — never a spread of the caller's `payload` — the deterministic net bounding the wire to
  exactly those three fields regardless of what the structural-minimum guard let through (the #236
  fresh-literal posture). A new `case 'conversation-created':` in `onDriverEvent` emits
  `conversationCreated` as a verbatim passthrough (the `conversations` precedent — nothing to drop).
- **Inbound decode** (`inboundMessage.ts`) — `parseConversationCreatedPayload`, fail-closed: four
  required strings + one required boolean (`is_promoted`, `false` decodes as a value) + one required-
  but-nullable string (`name`, cloning `requireStringOrNull` from #139). Narrows **before** logging so
  a malformed reply throws first and leaves no diagnostic record; the content-free log reuses the
  existing `{event, code, bytes, hash}` shape with no `count`.
- **Event arm** (`src/shared/ipc/events.ts`) — `conversationCreated{conversation}` joins `DaemonEvent`,
  reusing the wire type verbatim. Its doc-comment carries the untrusted-display-text warning forward
  for #242 — `name`/`cwd` are daemon-supplied strings that must render as plain text, never HTML —
  since this ticket has no DOM sink of its own.
- **Routing + exhaustive consumers** — `main/index.ts`'s `onCommand` switch gains one case
  (`connection.createConversation(command.payload)`); all three `assertNever`-guarded `DaemonEvent`
  consumers (`daemonEventBridge.ts`, `timelineBridge.ts`, `modalBridge.ts`) gain a one-line
  `case 'conversationCreated': return null` / fall-through — the compile error from a missing case
  *is* the AC6 coverage, caught by `npm run build`.

`npm test` (1035 passed, 3 pre-existing skips), `npm run typecheck`, `npm run build` all clean.

## Patterns established

- **A new `DaemonEvent` arm now costs three exhaustive-switch touches, not two.** By #241 the modal
  vertical (#223) has shipped, so `daemonEventBridge.ts`, `timelineBridge.ts`, and `modalBridge.ts`
  all had to gain a case — the same three-bridge cost #229 first hit and #229's own spec undercounted
  by one file before #223 merged. This is now the steady-state cost of any future `DaemonEvent`
  addition until a fourth exhaustive consumer exists.
- **Nullable-and-present vs optional is a load-bearing distinction, not a style choice.** The spec
  flagged this explicitly: the daemon's `*T` fields without `omitempty` mean the key is always on the
  wire with an explicit `null`, the deliberate *opposite* of the `Envelope.in_reply_to?` "never emit
  null" convention. Modeling `CreateConversationPayload`'s fields as `T | null` (not `T | undefined`)
  and asserting `'field' in value` (not just a type check) in the guard is what keeps a missing key
  rejected while a literal `null` is accepted.
- **A security-sensitive outbound command's guard is a structural minimum; the connection method's
  fresh-literal construction is the real net.** Reaffirms the #236 posture: `isCreateConversationPayload`
  tolerates a smuggled extra field, and `createConversation`'s fresh three-field literal (not a spread
  of `payload`) is what actually bounds the wire.

## Lessons learned

From the merged PR's own "Lessons learned" section:

- **`src/shared/**/*` sits in both tsconfigs, so a shared test must not import the main-process codec.**
  The spec suggested putting the `encodeEnvelope`/`decodeEnvelope` round-trip in `types.test.ts`. The
  developer kept that file to type-shape assertions (its existing idiom) and put the real codec
  round-trips in the transport tests (`createConversationEnvelope.test.ts` + `inboundMessage.test.ts`,
  where the codec is already imported) instead — importing `codec.ts` into a `src/shared` test would
  drag it into the renderer typecheck program, an edge CLAUDE.md's "keep the transport out of the
  window" split exists to prevent. AC7's "round-trip both shapes including null" is still fully
  covered through the real codec, just at the boundary-respecting location.
