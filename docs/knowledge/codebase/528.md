# #528 — a `reset` arm on `ThreadEvent`

Split from #508. Reducer-only capability slice, blocking #530 (conversation switch) and #531 (unpair /
pair-another-server), both of which own the dispatch sites. Spec `cd57ec1`, shipped `dc00c65`, zero
deviation from `docs/specs/architecture/528-timeline-reset-arm.md`. Size XS: 2 files touched
(`threadTimeline.ts`, `threadTimeline.test.ts`), zero fan-out — confirmed by the deterministic
`git diff --name-only main` check the spec's AC4 section specified.

## Summary

`timelineStore` is an app-lifetime singleton and `dispatch` is its sole write path, so once
`ThreadItem`s accumulated there was no way to empty the timeline for the rest of the process
lifetime — one conversation's rows survived into the next conversation's thread, one pairing's rows
into the next pairing's. This ticket ports [`sessionStore`'s `reset` arm (#166)](166.md) to the
timeline reducer:

- `ThreadEvent` gains a tenth arm, nullary, appended after `unrecognizedMessage`:
  `{ type: 'reset' }`. It is the first arm that is neither daemon- nor user-content-derived — a
  renderer-lifecycle control event, never translated from a wire frame, so `timelineBridge.ts` never
  produces it and needed no change.
- `reduceTimeline`'s new `case 'reset': return initialTimelineState` answers it by **returning the
  shared constant**, not a hand-written `{ items: [], phase: 'idle', … }` literal. That choice is
  what makes AC2's five-field equality an identity rather than a coincidence (a sixth `TimelineState`
  field added later is cleared for free), makes a second reset idempotent by reference for free
  (`reduceTimeline(initialTimelineState, reset())` returns the same reference), and keeps `items`
  itself the same reference post-reset — so a no-op reset churns no `selectItems` subscriber, where a
  fresh `[]` would re-render every one.
- No dispatch site ships here (AC4). `timelineStore.ts` needed no edit — `dispatch` was already typed
  `(event: ThreadEvent) => void`, so it accepts the widened union the moment it compiles.

## Files touched

- `src/renderer/src/store/threadTimeline.ts` — the `reset` arm + `case`, both carrying a rationale
  comment in the shape of the neighbouring arms (see the diff at `dc00c65` for the exact wording).
- `src/renderer/src/store/threadTimeline.test.ts` — a `reset()` fixture builder beside `stall()`, and
  a new `describe('reduceTimeline — reset')` block: clears all five fields from a fully-dirty state
  (precondition asserted first, the `sessionStore.test.ts:121-123` discipline), returns the shared
  constant by reference, is idempotent (twice in a row, and against an already-initial state), leaves
  `items` un-churned by reference, and does not let a later `run([...])` append corrupt the shared
  `initialTimelineState.items`.

Nothing else changed. `timelineStore.ts`, `timelineBridge.ts`, and every render site are untouched —
exactly what the spec's deterministic three-file diff check required.

## Patterns established

- **A capability-only reducer arm, ordered ahead of its call sites, is a legitimate split shape when
  the call sites are separately-owned tickets.** #530 and #531 are both natively blocked on this one
  and both already own their dispatch site in their own acceptance criteria; adding either site here
  would take work out of a ticket that exists for it. The architecture doc called out that this AC
  (AC4) is the one most at risk from a developer spotting an "obvious" call site — worth remembering
  as a general shape, not just for this ticket.
- **Returning the shared `initial*State` constant, not a fresh literal, is now a two-time precedent**
  (`sessionStore` #166, `threadTimeline` #528) for any "reset to blank" reducer arm in this codebase.
  It buys three things simultaneously — forward-compatible field coverage, free idempotence, and
  no-churn same-reference selectors — that a hand-written literal loses silently (it would still
  compile with a stale field). Any future reset-shaped arm should default to this shape unless there's
  a specific reason the state can't be a shared constant.
