## Patterns established

- **A deletion that falsifies a self-describing comment ("count the JSX, not these comments") must be
  checked by the exact method the comment prescribes** — count the surviving JSX, not just decrement
  the stale numbers by one. Confirmed independently by code review against `App.tsx:122-129`.
- **Pin the expected post-deletion grep residual as a table in the spec, not as a vague "check nothing
  else references it."** Turns "did I finish?" into a diff against a fixed list instead of a judgment
  call — the twelve-line census here matched the spec's table line-for-line, and review re-ran the
  same grep independently and got the same twelve.
- **A removal series that spans multiple tickets should carve out stranded comment citations to one
  sweep ticket at the tail** ([#635](https://github.com/pyrycode/pyrycode-desktop/issues/635)), rather
  than re-anchoring them partially in each slice — #620–#622's strandings become visible in the same
  pass as this ticket's twelve.

## Lessons learned (from the PR body)

- **An AC phrased as "no module imports X" cannot be answered by a plain name grep** — the same grep
  that proves the import criterion also surfaces every deliberate non-import citation (twelve of
  them, here). Having the spec pin the exact expected residual as a table is what makes a name grep
  usable as evidence for an import-scoped AC at all.
