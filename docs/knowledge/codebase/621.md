## Patterns established

- **Deleting the type and reading `tsc`'s error list beats grepping for the fan-out.** The architect
  measured this at spec time (22 errors / 16 files across both `tsconfig` projects) and the developer's
  own testing confirmed it: `npm run typecheck`'s `&&` hides the entire renderer half behind the node
  half's exit code, so iterating requires running `tsc -p tsconfig.web.json` directly. See [[prove
  compile-atomicity by deleting the type]] memory.
- **A citation-direction invariant catches a spec error before it ships.** The ticket body prescribed
  re-pointing `daemonEventBridge.ts:111` (`sessionTransition`) at the new `stallDetected` origin: the
  architect's spec caught that this would be the file's first *backward* citation (every other citation
  in the file points at an arm above it) and corrected the remedy to drop the clause instead of
  re-pointing it. Worth checking for on any future precedent-chain-origin removal: verify citation
  direction across the *whole* file, not just the arm being edited.
- **A "sample of unrelated events" fixture array has a minimum viable size.** Five of six inert-fixture
  files tolerated a clean one-line drop because each kept ≥3 members after; the sixth
  (`logDataDownload.test.ts`) had exactly three, so dropping one would have left two nullary arms and
  no payload-carrying event — silently weakening what the test claims to assert. The fix is a
  same-shape swap (`runConfigReceived` for `snapshotReceived`), not a drop, when the array is already
  at the edge of that property.
- **Two arms sharing one emit choke point must be removed together — there is no seam to split on.**
  `snapshotReceived` and `screenSnapshotReceived` were both emitted from the same `case 'snapshot':`
  block since #316; removing one without the other would leave a dangling half-emit and fail AC3 ("a
  `screen_snapshot` frame produces no daemon event *at all*"). The architect's spec evaluated and
  rejected a by-arm split for exactly this reason.

## Lessons learned (from the PR body)

- Deleting a union member and reading `tsc`'s error list beats grepping for the work: both projects
  named all 22 sites, and `npm run typecheck`'s `&&` short-circuits, hiding the entire renderer half
  until the node half is green — run `tsc -p tsconfig.web.json` directly while iterating.
- A "verify against the base commit" control is worth the two minutes: the real-daemon spec's failure
  looked like an AC5 regression and was pre-existing. Stash → rebuild → rerun answers it definitively.
