## Patterns established

- **A comment-stripped diff is the only mechanical proof that a "comment-only" sweep touched no
  executable line.** `npm run build` can't see it (`noUnusedLocals` is off, so an orphaned import still
  compiles; every touched guard returns `boolean`, so a mangled guard body still typechecks). Strip
  `//`, `/* */`, and leading ` * ` lines from both revisions and diff the residue — empty residue is
  the proof. See [[comment-stripped diff proves a sweep touched no code]].
- **A dangling comparative can be un-re-anchorable by construction, not merely inconvenient.** Decision
  H's `conversation.not_found` was the deleted verb's *own* property, never a survivor's — the
  tree-wide count was four hits, all comments, zero literals. Any name swap there would inject a false
  security claim rather than merely a stale one; the correct move is to state the surviving claim's own
  shape and drop the comparative, not to search harder for a target.
- **A re-anchor target must not be one of the citing sites, and must actually carry the cited
  property.** `buildSendMessage` qualified on both counts where the four citing builders
  (`buildCreateConversation`, `buildDequeueMessage`, `buildModalResolution`, `buildSetSessionSettings`)
  would have created a self-citation cycle, and where `createConversationEnvelope` looked
  payload-carrying but didn't actually carry the `conversation_id` **selector** decision E needed.
- **A boundary sweep for a retired verb needs `-i`.** `buildRequestSnapshot` (capital R) accounted for
  13 of the 24 tree-wide hits, in files a case-sensitive grep would have missed entirely — confirmed by
  #620's own follow-on measurement. See [[a removal-sweep grep AC is case-blind without -i]].

## Lessons learned (from the PR body)

- A bare `ts.createScanner` is not a reliable comment-stripper: without a parser driving
  `reScanTemplateToken` it desyncs on template-literal boundaries and leaked 24 comment lines into its
  own residue on this branch's e2e spec, reporting a false "executable line changed". A string-aware
  line-level stripper (treating a backtick span as opaque) leaked zero on the same file and needs no
  `node_modules`.
- Validate a stripper before trusting an empty diff — an empty residue is vacuous if the stripper emits
  nothing. Two controls settle it: mutate an executable line (must be detected) and mutate a comment
  (must not be).
- The residue diff catches what `noUnusedLocals: false` hides: import lines survive stripping, so an
  edit that orphans an import shows up as a residue change even though `tsc` stays green.
