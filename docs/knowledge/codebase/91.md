Delivers the missing **responder** as an in-process TypeScript fake daemon: it completes the `Noise_IK_25519_ChaChaPoly_BLAKE2s` handshake as the responder (reads IK msg1 recovering the client static + `hello` early-data, writes msg2 carrying `hello_ack`, splits into transport ciphers), then decrypts one inbound message envelope and streams a sealed reply while keeping the session open. It dials the #90 content-blind forwarder's `/v1/server` leg and uses the production `codec` framing + the exact `NOISE_PROTOCOL` constant — no hand-rolled shortcut. ## Design in one paragraph

Mirror `noiseSession.ts` as a responder. `HandshakeState(NOISE_PROTOCOL, NOISE_ROLE_RESPONDER)`, `Initialize(null, staticPriv, null, null)` (responder passes its static private; `rs = null` — IK recovers the initiator static from msg1; empty prologue → `null`). One leg `message` handler is the whole state machine: on msg1, `ReadMessage` recovers the `hello`, `decodeEnvelope` confirms it well-formed (faithfulness), `WriteMessage(encodeEnvelope(hello_ack))` produces msg2, `Split()` yields the transport ciphers with **no swap** (see Lessons), and the session moves to `transport` where each inbound frame `DecryptWithAd` → `buildReply` → `EncryptWithAd` → send. The one untrusted→trusted seam is the leg boundary (`base64StdDecode(decodeInnerFrame(bytes).data)`), fail-closed to `frame-decode-failed`, the inner `type` never branched on (the Noise state machine + AEAD decide interpretation, mirroring `noiseRelayDriver.onMessage`). Every failure settles a static `FakeDaemonOutcome` reason via the cached `whenSettled()` deferred — a diagnostic aid so a daemon-side fault surfaces crisply rather than as a mysterious client-side timeout; the round-trip assertion is the primary oracle.

## Patterns established

- **A faithful fake is the deliberate inverse of a content-blind one.** #90's forwarder proves a boundary component *can't* peek by making the peeking unimportable (imports only `ws`). #91 is the opposite: the fake daemon **must** be faithful, so it imports the production `codec` + `NOISE_PROTOCOL` + `noise-c.wasm` and is held to it by ACs. The two modules sit side by side in `transport/` as the two halves of one harness, and their import lists document which discipline each obeys. When you need a fake peer for a crypto/protocol round-trip, faithfulness (real codec, real suite, real library) is the requirement — a hand-rolled shortcut would let the fake pass while diverging from the real daemon and give false confidence.
- **Pin a stochastic crypto detail with a deterministic oracle, not with reasoning.** The `Split()` send/recv role-mapping (AC4) is exactly the kind of load-bearing detail where confident reasoning can still be wrong. The round-trip test **is** the coverage: a crossed mapping completes the handshake but MAC-fails the first transport frame, so the assertion fails hard and deterministically. Belt-and-suspenders with a *deterministic* net (CLAUDE.md), written test-first so the oracle exists before the mapping is committed.
- **`whenSettled()` as a diagnostic sealed-union outcome.** A daemon-side failure that would otherwise present as a client-side timeout is turned into a crisp `{ ok:false, reason }` from a closed set of static reasons — mirroring the Go interop responder's `ERR <reason>` line and the codebase's discriminated-union discipline. It is a diagnostic aid, not the primary oracle; the round-trip assertion is.
- **Test-only infra stays out of production by construction + verification.** The module carries a test-only header comment naming the invariant (never import into `src/main/index.ts` / `preload` / `renderer`), and the PR verified it is absent from the built `out/main/index.js` bundle — the same way `fakeRelayForwarder.ts` stays test-only. A second Noise static-key holder + permissive `ws://` dialer in production is the concrete harm being prevented.
- **Await `startFakeDaemon` before wiring the client.** Awaiting the factory (which resolves only after the `/v1/server` leg is `open` with its handler armed) guarantees the forwarder has registered the server leg before the client's msg1 is sent — so the forwarder's "peer not connected → drop silently" path can't eat the first frame.

## Lessons learned

*Lifted from the PR body's "Lessons learned" section.*

- **`noise-c.wasm` `Split()` returns `[send, recv]` role-adjusted for BOTH roles**, so the responder uses the SAME mapping as the initiator — `sendCipher = split[0]`, `recvCipher = split[1]`, **no swap**. This is the opposite of the `flynn/noise` responder (`noiseSpikeResponder/main.go`), which returns the raw pair and forces a manual `recv=cs1, send=cs2` swap. Confirmed against `node_modules/noise-c.wasm/src/index.js:542` (`@return [send, receive]`). A crossed mapping completes the handshake but MAC-fails the *first transport frame*; the round-trip test pins it as a deterministic oracle (verified: crossing it makes the test fail with `transport-decrypt-failed`). This is not merely a functional bug — a crossed mapping would encrypt under the same `(key, nonce-0)` the initiator uses for its own outbound, a catastrophic key/nonce-reuse class error, which is why AC4 demanded a deterministic test.
- **Awaiting `startFakeDaemon` before wiring the client** guarantees the forwarder has registered the `/v1/server` leg before the client's msg1 is sent, so the forwarder's "peer not connected → drop silently" path can't eat the first frame.

## Testing

Five cases, all in-process over loopback `ws` (no Go toolchain, no network — AC6):

- **Self-verifying round-trip (AC1–AC6) — the core.** Stand up `startFakeRelayForwarder()` → `startFakeDaemon({ url })`, wire the real client half (`createRelayConnection` on `/v1/client` + `createNoiseSession` with `remoteStaticPublicKey: daemon.staticPublicKey` + the codec `sendFrame`/`onFrame` glue, fresh in-process client static, a **dummy** token in the `hello`), `await forwarder.whenReady()`, then assert in order: client emits `handshake-complete` and `parseHelloAck(event.helloAck)` deep-equals the daemon's `{ protocol_version:'v2', server_id:'fake-daemon', conn_id:'conn-1', capabilities:[] }` (proves msg2 read + AC3 ack build); `sendMessage(probe)` → client emits `message` whose `plaintext` equals the probe bytes (proves the AEAD round-trip + **AC4** — a crossed Split MAC-fails here); no client `error`; `daemon.whenSettled()` is `{ ok:true }`; `forwarderUrl` matches `ws://127.0.0.1:<port>`.
- **Custom `buildReply` + session stays open (AC2).** A canned `message` envelope is streamed back sealed; a **second** inbound frame decrypts + replies again → two `message` events, no error (proves AC2's "keeps the session open").
- **Log-free across handshake + transport + a client error path (security).** Spy every `console.*`, drive a full round-trip, then feed the client a garbage transport frame; assert `console` never called and the daemon settled `{ ok:true }`. Mirrors `noiseSession.interop.test.ts:345-362`.
- **Fail-closed at the leg boundary (security).** A raw `ws` on `/v1/client` sends a non-`InnerFrameV2` text frame (`"{not json"`); `daemon.whenSettled()` resolves `{ ok:false, reason:'frame-decode-failed' }` and nothing throws/logs.
- **Teardown idempotent.** `close()` twice → both resolve, no throw; a pre-completion `close()` settles `whenSettled` as `{ ok:false, reason:'closed' }`.
